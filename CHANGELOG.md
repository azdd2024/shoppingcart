# Changelog

## Unreleased (next major release)

### Requirements
- PHP `^8.3` is now required (8.3, 8.4 and 8.5 are covered by CI).
- Supported Laravel versions: 11.x, 12.x and 13.x. Support for Laravel 9 and 10 has been dropped: they cannot run with the new PHP minimum together with the supported dependency set, and both are end-of-life.
- `nesbot/carbon` constraint updated to `^2.72.2||^3.0` (the versions accepted by Laravel 11–13).
- `illuminate/database` is now declared explicitly, because `Cart` uses `Illuminate\Database\DatabaseManager` for `store()`, `restore()`, `merge()` and `erase()`. It is part of every Laravel application, so nothing new is installed.

### Public API
- No public or protected method, property, constant, facade, alias, config key, event name or exception has been renamed, removed or re-typed. Parameter names, order and default values are unchanged and are covered by a reflection test.
- The serialized format of `CartItem` (used by the session and by the `shoppingcart` table) is unchanged; a test restores a payload generated by the previous version.
- The fork specific behaviour of `DefaultCalculator` (the discount is not subtracted from `subtotal`) is preserved and now documented in the README and in the tests.

### Behaviour change in an invalid-input path
- `CartItem::__construct()` no longer calls `strlen()` on the price and weight. The removed check (`strlen($x) < 0`) could never be true; on PHP 8.1+ it raised a deprecation for `null` values and a `TypeError` for arrays or objects. Invalid prices and weights now always throw the documented `InvalidArgumentException` ("Please supply a valid price." / "Please supply a valid weight."). Valid input behaves exactly as before.

### Performance
- `CartItem` validates the configured calculator class with reflection only once per class name per process instead of on every computed attribute. The configuration is still read on every access, so changing `cart.calculator` at runtime keeps working.
- `Cart` reads the session once per content access instead of twice (`has()` + `get()`).
- `restore()` and `merge()` run one query instead of two (`exists()` + `first()`), `erase()` runs one `DELETE` instead of `exists()` + `DELETE`, and the database connection is resolved once per call.
- Totals are summed with a plain loop instead of `Collection::reduce()`; the order of the additions, and therefore the floating point result, is the same.

Measured on PHP 8.3.6 / Laravel 13.37 (best of 5 runs, same inputs for both versions):

| Operation | Before | After | Gain |
|-----------|-------:|------:|-----:|
| add 100 items (x20) | 17.75 ms | 12.46 ms | 30% |
| all totals, 100 items (x50) | 258.10 ms | 171.21 ms | 34% |
| update 100 items (x20) | 19.43 ms | 11.36 ms | 42% |
| `content()->toArray()`, 100 items (x50) | 149.72 ms | 96.19 ms | 36% |
| store + restore, 100 items (x10) | 5.12 ms | 4.40 ms | 14% |
| all totals, 1000 items (x5) | 272.92 ms | 161.18 ms | 41% |
| `$item->total` x10000 | 225.81 ms | 143.64 ms | 36% |

### Code
- Constructor property promotion and `readonly` for the session and event dispatcher of `Cart`, `match` instead of `switch` in the calculators and magic getters, `??=` in the number formatting helpers, typed private helpers.
- Duplicated code for persisting a single item and for (un)serializing the stored content has been extracted into private methods.
- All block comments and docblocks have been removed from the PHP sources and tests; the configuration options are documented in the README.

### Tests and tooling
- Test annotations migrated from `/** @test */` to the `#[Test]` attribute (required by PHPUnit 12).
- New `tests/CompatibilityTest.php` with 53 additional tests: service container and facade, configuration and publishing, session layout, instance isolation, row id stability, serialized format and restore of a cart stored by the previous version, events order, edge cases of quantities, prices and weights, calculator switching, public method signatures.
- The full suite passes with the original sources and with the new ones on Laravel 11, 12 and 13.
- `phpunit.xml` migrated to the PHPUnit 10+ schema; only `*Test.php` files are collected.
- Added PHPStan (level 5) with `phpstan.neon.dist`.
- GitHub Actions: test matrix PHP 8.3–8.5 × Laravel 11–13, PHPStan job, updated actions. The Codecov upload was removed because it requires a token and made the build fail without one.
- `.gitignore` now excludes `vendor/` and `.phpunit.cache/`.
